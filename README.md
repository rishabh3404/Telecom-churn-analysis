# Telecom Churn Analysis

Customer churn analysis project using Python, SQL, Excel, and Power BI.

## Project Overview

This project analyzes telecom customer data to identify churn patterns, customer behavior, and key business factors associated with customer attrition.

## Objectives

- Analyze customer churn patterns
- Clean and prepare customer data
- Perform SQL-based analysis
- Explore data using Python
- Build Power BI dashboards
- Identify important churn-related business patterns

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Microsoft Excel
- Power BI
